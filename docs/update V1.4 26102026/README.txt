การจัดการคอมเม้นท์
------------------
1. มาตรฐานชื่อบทบาทผู้ใช้งาน + Mapping   ข้ามไว้ก่อน รอสรุปจากทีม (สถานะ "ยังไม่แก้" ในตารางผลกระทบ v.2)
2. ชื่อใน DFD สั้น กระชับ                 ย่อชื่อ Process / Data Store / Data Flow ให้อยู่ในหน้าเดียว
3. ใช้ชื่อระบบแทน "กิจกรรม"               ปรับในเนื้อหาเล่ม (คงไว้เฉพาะหน้าปกและประวัติการแก้ไข)
4. ขั้นตอนออกเลขจากระบบสารบรรณ            UF: RES033, RES135–RES137, RES219 / DFD: เพิ่ม E11 ระบบสารบรรณอิเล็กทรอนิกส์
5. Process ขึ้นต้นด้วย "กระบวนการ"         ทุกกล่อง Level 1 และ Level 2
6. ความคมชัด User Flow                    จัด layout ให้แน่นขึ้น ตัวอักษรใหญ่ขึ้น export 2 เท่า และตั้งหัวข้อ 2.1 ในเล่มเป็นแนวนอน
7. ขนาดตัวอักษร DFD Level 1–2             ทุกกล่อง/ข้อความขนาด 34 เท่ากัน และแก้ Data Store ไม่ให้ล้นกรอบ

สิ่งที่ต้องทำก่อนส่งลูกค้า
------------------------
1. เปิดเล่ม 4 V1.4 ใน Word เมื่อขึ้นถามอัปเดตฟิลด์ให้กด "ใช่" (เลขรูป/ตาราง/สารบัญจะถูกอัปเดต)
   จากนั้นตรวจเลขหน้าในตารางผลกระทบ v.2 (เลขหน้าที่ใส่ไว้มาจากการเปิดด้วย LibreOffice อาจคลาดเคลื่อน 1–2 หน้า)
2. ใส่ชื่อผู้ดำเนินการในตารางประวัติการแก้ไขของเล่ม 4 แถวเวอร์ชัน 1.2–1.4
3. รูปในโฟลเดอร์นี้ render ด้วยฟอนต์ทดแทน (Sarabun / Noto Sans Thai) หากต้องการฟอนต์ TH Sarabun New ตรงตามเครื่อง
   ให้เปิดไฟล์ .drawio ในเครื่องที่มีฟอนต์แล้ว Export PNG ใหม่ (ตำแหน่ง/ข้อความเหมือนเดิม)
4. ชีต "ทะเบียนสมมติฐาน" เป็นข้อมูลภายใน ควรลบหรือซ่อนก่อนส่งตารางให้ลูกค้า
   หากทีมหรือลูกค้ายืนยันข้อมูลจริงต่างจากสมมติฐาน ให้แก้ตามรายการ "สิ่งที่เปลี่ยน" ของข้อนั้น
5. คอมเม้นท์ข้อ 1 ยังค้าง เมื่อได้สรุปชื่อบทบาทจากทีม ต้องปรับ Lane ของ User Flow, External Entity ใน DFD และคำอธิบายในเล่มอีกรอบ

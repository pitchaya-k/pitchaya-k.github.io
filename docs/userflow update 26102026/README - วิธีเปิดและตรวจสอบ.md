## วิธีอ่านผัง
- วงกลมขอบบาง "เริ่ม" = จุดเริ่มต้น / วงกลมขอบหนา = จุดสิ้นสุด
- กล่องมุมมน = ขั้นตอนของผู้ใช้ (รหัส RES เดิม) / ข้าวหลามตัด = จุดตัดสินใจ (รหัส DEC- แทน D เดิม)
- วงกลมคู่ลูกศรทึบ = "ไป", ลูกศรโปร่ง = "มาจาก" — จับคู่ด้วยตัวอักษรเดียวกันในหน้าเดียวกัน
- `[รอยืนยัน Qn]` = ประเด็นที่ยังต้องยืนยัน ดูรายละเอียดในไฟล์ 1791976367965.docx หัวข้อ 7

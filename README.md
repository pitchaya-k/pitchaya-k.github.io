## เปิดต้นแบบ
1. เปิด PowerShell แล้วรันเว็บเซิร์ฟเวอร์ที่โฟลเดอร์ต้นแบบ

   ```powershell
   python -m http.server 8765 --directory "C:\Users\USER\Downloads\Code Prototype_Activity 7\pitchaya-k.github.io"
   ```
2. เปิด `http://localhost:8765/login.html` (รวม Option A+B) · `http://localhost:8765/A7-Option-A-03112026/login.html` · `http://localhost:8765/A7-Option-B-03112026/login.html`
3. กดปุ่มเข้าสู่ระบบด่วนของบทบาทที่ต้องการ แล้วสลับบทบาทได้ที่ช่อง "สิทธิ์การทำงาน" มุมขวาบน
4. เดินตามชีต "ขั้นตอนการกด" ในไฟล์ Excel ของโฟลเดอร์ `06 ต้นแบบ Prototype`

ข้อควรรู้
- เปิดหน้าได้โดยไม่ต้องต่ออินเทอร์เน็ต แต่ข้อมูลสำนวนจริงมาจาก Supabase ซึ่งต้องต่ออินเทอร์เน็ต
- **ปุ่มดำเนินการในต้นแบบเขียนลงฐานข้อมูลที่ใช้ร่วมกันทั้งทีม** กดแล้วสถานะเรื่องเปลี่ยนจริง ถ้าแค่สาธิตหน้าจอให้ใช้ภาพในชีต "ภาพหน้าจอ" ของไฟล์ Excel
